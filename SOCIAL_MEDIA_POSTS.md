## 👾 3. Reddit Post (r/artificial, r/GoogleCloud, r/LocalLLaMA)

### Title:
> Built an Ambient Voice AI & MCP Grounding Layer for 500+ page enterprise manuals (Gemini 2.0 + Cloud Run + React 19)

### Body:
```markdown
Hey everyone! For the AI Tinkerers *Agents, Everywhere* Global Hackathon, I built **ActWise Live** — an ambient voice agent designed to solve a huge friction point in enterprise compliance: navigating monolithic 500+ page NICE Actimize documentation.

### The Problem
In financial surveillance and AML platforms, engineers and compliance teams constantly struggle with dense PDF guides. When setting up ActOne 10.2 or configuring DART real-time streaming, a wrong config parameter breaks transaction monitoring. Standard LLMs hallucinate parameters, and chat interfaces force you to stop what you're doing.

### How ActWise Live Solves It
1. **Voice with Low Latency**: Gemini 2.0 / 3.8 Flash with Aoede speech synthesis. It speaks concise 1-2 sentence executive summaries while streaming the full technical procedure on screen.
2. **Model Context Protocol (MCP)**: Directly connects to the ActWise DOCenter MCP server (`search_docs`, `get_page`). Zero answers from memory — every claim includes Markdown citation links to verified documentation.
3. **Interactive UI Widgets**: Converts procedures into reactive step checklists (`<InstallationChecklist />`) and side-by-side version matrices (`<VersionCompareMatrix />` showing +NEW, ENHANCED, DEPRECATED badges).
4. **Ambient Sidecar Extension**: Manifest V3 Chrome extension to highlight error codes on any internal tab for instant voice answers.
5. **Production Cloud Run**: Containerized Node/React 19 stack running live on Google Cloud Run.

- **Live Demo**: https://actwise-live-218423701961.us-central1.run.app
- **GitHub**: https://github.com/vinayguda/ActWise-Live
- **1080p Video**: In the GitHub repo (`recordings/ActWise_Live_Demo_Submission.mp4`)

Would love any thoughts and feedback on the MCP integration and voice UX!
```
